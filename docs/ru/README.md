## 🚀 Быстрый старт

1. **Подготовьте окружение:**
   ```bash
   make keygen
   cp src/env.example src/.env
   # Отредактируйте src/.env, добавив ключи API
   ```

2. **Соберите и запустите:**
   ```bash
   make clean
   make build
   make run
   ```

3. **Сгенерируйте первый плейбук:**
   ```bash
   python src/cli.py generate \
     --description "Install nginx web server" \
     --hosts "web_servers" \
     --inventory "/app/ansible_playbooks/inventory"
   ```

## 🔧 Ключевые компоненты

### Интеграция с LLM (`src/llm/`)
- **PlaybookGenerator**: генерация плейбуков через OpenAI/Anthropic
- **TemplateManager**: система шаблонов Jinja2 для переиспользуемых сценариев

### Слой API (`src/crud/`)
- **Приложение FastAPI**: REST API с автоматической документацией
- **Эндпоинты**: генерация плейбуков, управление шаблонами, планирование задач

### Слой данных (`src/models/`, `src/db/`)
- **Модели SQLAlchemy**: схема базы данных для задач и шаблонов
- **Интеграция с Celery**: асинхронное выполнение и планирование задач

### Конфигурация (`src/config.py`)
- **Управление окружением**: централизованная конфигурация с валидацией
- **Поддержка LLM-провайдеров**: интеграция с несколькими провайдерами ИИ

## 🛡️ Механизмы безопасности

- **Обнаружение опасных конструкций**: блокировка небезопасных операций
- **Уровни безопасности**: настраиваемая строгость проверок
- **Валидация YAML**: проверка корректности сгенерированных плейбуков
- **Проверка прав**: контроль повышения привилегий

## 📄 Лицензия

Файла лицензии в репозитории пока нет, то есть правовой статус кода не определён:
использовать, изменять и распространять его никто не вправе, пока лицензия не появится.
Планируемый выбор — Apache-2.0: он совпадает с окружающей экосистемой (AWX и
`ansible-runner` под Apache-2.0), а явный патентный грант важен для инструмента, который
может поставляться вендором. Добавление лицензии упирается в вопрос о правообладателе.

Важно для контрибьюторов: не импортируйте `ansible.*` напрямую. `ansible-core` под
GPLv3, и именно вызов его отдельным процессом через `ansible-runner` (Apache-2.0)
оставляет выбор лицензии свободным.
